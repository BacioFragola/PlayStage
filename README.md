# PlayStage

PlayStage is an research framework for comparing human dramatic speech and AI-generated speech through multi-layer acoustic token visualization.

The project explores how discrete acoustic token patterns may reveal differences between human theatrical performance and synthetic speech, especially under expressive, high-tension, and dialogue-based conditions.

At the current stage, PlayStage focuses on:

- visualising multi-layer acoustic token trajectories;
- comparing human actor recordings with AI-generated speech;
- developing preliminary metrics for token-level discrepancy analysis;
- supporting future experiments on expressive and context-aware speech synthesis.

This repository is currently under active development.
