# PlayStage

A research framework for analyzing and evaluating multi-layered discrete acoustic token distributions in generative speech synthesis architectures under dramatic and spontaneous prosody conditions. 

This repository provides tools to profile codebook dynamics, measure token discrepancy against human theatrical references, and design control strategies for high-tension and interactive vocalizations.

---

## Repository Structure

* **`configs/`**: Configuration manifests for multi-turn dialogues, speaker conditioning, and structural prompt attributes.
* **`scripts/`**: 
  * Pipeline implementations for controlled, multi-turn speech generation.
  * Extraction and entropy calculation modules for multi-layer discrete acoustic tokens.
  * Spatial-temporal visualization engines for comparative codebook analysis.

## Key Focus Areas

* **Acoustic Token Discrepancy Analysis**: Quantifying the micro-structural gap between synthetic speech and real-world dramatic performances across multiple codebook tiers.
* **Codebook Behavior Profiling**: Investigating localized token homogeneity, distribution patterns, and entropy shifts during non-verbal expressions or structural pauses.
* **Controllable Dramatic Synthesis**: Exploring parameter manipulation strategies within contemporary discrete token architectures to enhance emotional range and contextual continuity in multi-turn domains (e.g., interactive media, gaming).
